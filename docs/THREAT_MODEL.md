# Threat model

Attacker controls user input, external responses and LLM output, and may try to induce unauthorized effects or disclose secrets. Defender controls reviewed Python source and a declared model of library APIs. Critical assets are payment/action APIs, external writes and sensitive local data. The analysis is pre-execution and has no authority over deployment, dependencies, credentials, human decisions or model behavior. A hostile developer or compromised dependency can invalidate API models. Validation is a trusted *contract*, not a proof that arbitrary `validate` code works; authorization is similarly a trusted binding of a decision to the exact action payload. Treat ambient effects, import-time execution, reflection and unknown call targets as uncertainty. No property here establishes semantic harmlessness of an LLM response.
